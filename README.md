# 💪 BMI Calculator

A simple, responsive, and interactive web-based Body Mass Index (BMI) Calculator that allows users to calculate their BMI based on their weight and height.

🌐 **Live Demo:** [View BMI Calculator](https://rithmymanathunga.github.io/BMI---Calculator-/)

---

## 📌 Project Overview

The BMI Calculator is a lightweight web application designed to help users calculate their Body Mass Index quickly and easily.

Users can enter their weight in kilograms and height in centimetres to calculate their BMI and view the corresponding BMI category.

The application features a colourful animated interface, interactive effects, and options to download or copy calculation results.

## ✨ Features

- **BMI Calculation** – Calculates BMI using weight and height.
- **BMI Categories** – Displays Underweight, Normal, Overweight, or Obese categories.
- **Input Validation** – Prevents empty, zero, negative, and invalid input values.
- **Animated Background** – Features a continuously animated gradient background.
- **Confetti Effects** – Adds interactive visual effects during use.
- **Download Results** – Allows users to download their BMI result as a PNG image.
- **Copy Results** – Copies the calculated BMI result to the clipboard.
- **Social Sharing** – Provides links for sharing the calculator through social platforms.
- **Responsive Design** – Supports desktop and mobile screen sizes.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- An internet connection for external resources such as Google Fonts and the Confetti library.

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/rithmymanathunga/BMI---Calculator-.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation is required.

## 📐 BMI Classification

The calculator uses the following standard adult BMI categories:

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25.0 – 29.9 | Overweight |
| 30.0 or above | Obese |

*Note: These categories are general adult BMI classifications. BMI is a screening measure and does not independently determine an individual's overall health.*
